## 1. 核心计算公式速查

### EV（期望值）
```
EV = 模型概率 × 赔率 - 1
EV > 0 → 有价值（长期期望盈利）
```

| 玩法 | EV门槛 | Kelly系数 | 过关上限 |
|------|--------|-----------|----------|
| 胜平负 | +5% | 0.25 | 8关 |
| 让球胜平负 | +5% | 0.20 | 8关 |
| 总进球 | +7% | 0.20 | 6关 |
| 比分 | +15% | 0.03 | 4关 |
| 半全场 | +12% | 0.05 | 4关 |

### Kelly公式
```
Full Kelly = (模型概率 × 赔率 - 1) / (赔率 - 1)
实际使用 = Full Kelly × Kelly系数（0.03-0.25）
```

### 串关奖金
```
单注奖金 = 2元 × 赔率1 × 赔率2 × ... × 赔率N × 倍数
M串N注数 = 2^M - 1（3串4、4串11、5串26）
```

## 3. 资金管理与保本策略

### 三层资金结构
| 层级 | 占比 | 用途 | 风险 |
|------|------|------|------|
| 稳健层 | 50-60% | 胜平负/让球稳胆2串1 | 低 |
| 容错层 | 25-35% | M串N容错（3串4/4串11） | 中 |
| 搏冷层 | 10-15% | 比分/半全场高赔博冷 | 高 |

### 4种保本组合方案
1. **全包保本**：3场比赛，每场双选，组成3串1
2. **2串1+3串4**：2场稳胆做2串1（保本底仓）+ 3场比赛做3串4
3. **共享稳胆+反向**：1场超级稳胆共享到所有投注单
4. **M串N复式**：4场比赛，每场1-2个选项，组成4串11

## 4. 6大高级分析维度

1. **盘口语言识别**（8种模式）：初盘低水→终盘高水=诱盘等
2. **理论vs实际盘口偏离**：偏离>0.5球→有价值机会
3. **多视角分析**（5模块）：数据/模型/盘口/基本面/逆向
4. **反向指标分析**：热门陷阱/冷门价值/赔率异动/支持率背离
5. **CLV追踪**：赔率变动价值>10%
6. **联赛专攻分析**：联赛特征/球队风格/裁判因素/赛季阶段

## 5. 7大被忽略维度

1. 赛程疲劳（72小时内→体能下降10-15%）
2. 天气影响（大雨→进球减少）
3. 裁判因素（出牌多→比赛中断多）
4. 主场优势（不同联赛不同）
5. 球队风格克制
6. 更衣室氛围（内讧/换帅/转会传闻）
7. 旅行距离（>1000公里→表现下降5-10%）

## 6. 7大典型错误自检（输出前必须检查）

1. ❌ 只看赔率不看概率 → 必须计算EV
2. ❌ 串关过长（>6场）→ 命中率指数下降
3. ❌ 追热门不看诱盘 → 必须检查支持率背离
4. ❌ 忽略伤停影响 → 必须量化伤停影响
5. ❌ 比分/半全场仓位过重 → Kelly系数必须低
6. ❌ 单场比赛多选矛盾选项 → 胜平负主胜和比分客胜不能同时串
7. ❌ 不做保本结构 → 必须有稳健层底仓

## 7. 官方规则速查

### 过关上限
| 玩法 | 最大串关 |
|------|---------|
| 胜平负 | 8关 |
| 让球胜平负 | 8关 |
| 总进球 | 6关 |
| 比分 | 4关 |
| 半全场 | 4关 |

### 其他规则
- 单票金额≤6000元
- 倍数范围：2-99倍
- 每注固定2元
- M串N公式：N=2^M-1
- 混合过关上限由最低玩法决定
- 单注奖金≤500万（超过按500万计）

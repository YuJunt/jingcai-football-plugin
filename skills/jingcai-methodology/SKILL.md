# 竞彩足球通用方法论（知识层）

> 本技能是竞彩足球的**知识层**，提供分析和决策的理论依据。
> 由 `jingcai-core`（编排层）在分析阶段按需调用，不需要每次都完整读取。

## 一、核心计算公式

### 1.1 EV（期望值）计算

```
EV = 模型概率 × 赔率 - 1

EV > 0 → 有价值（长期期望盈利）
EV = 0 → 公平（长期不亏不赚）
EV < 0 → 无价值（长期期望亏损）
```

**分玩法EV门槛**：
| 玩法 | EV门槛 | 说明 |
|------|--------|------|
| 胜平负 | +5% | 概率可靠，门槛低 |
| 让球胜平负 | +5% | 概率可靠，门槛低 |
| 总进球 | +7% | 概率中等，门槛中 |
| 比分 | +15% | 概率不可靠，门槛高 |
| 半全场 | +12% | 概率不可靠，门槛高 |

### 1.2 Kelly公式（仓位计算）

```
Full Kelly = (模型概率 × 赔率 - 1) / (赔率 - 1)
实际使用 = Full Kelly × Kelly系数（0.05-0.25）
```

**分玩法Kelly系数**：
| 玩法 | Kelly系数 | 说明 |
|------|-----------|------|
| 胜平负 | 0.25 | 稳胆，仓位高 |
| 让球胜平负 | 0.20 | 较稳，仓位中高 |
| 总进球 | 0.20 | 中等，仓位中 |
| 比分 | 0.03 | 高赔，仓位极低 |
| 半全场 | 0.05 | 高赔，仓位极低 |

### 1.3 隐含概率与去水

```
隐含概率 = 1 / 赔率
去水后概率 = 隐含概率 / 返还率

竞彩返还率约73%（胜平负），比分/半全场约65-70%
```

### 1.4 串关奖金计算

```
单注奖金 = 2元 × 赔率1 × 赔率2 × ... × 赔率N × 倍数
M串N注数 = 2^M - 1（3串4、4串11、5串26）
保本条件 = 最低命中场次的奖金 ≥ 总投入
```

## 二、概率模型方法论

### 2.1 泊松分布模型

```
P(进球数=k) = (λ^k × e^(-λ)) / k!
λ = 预期进球数（主队进攻强度 × 客队防守强度 × 主场优势）
```

**适用场景**：总进球、比分、胜平负概率推导

### 2.2 Dixon-Coles修正

```
对低比分（0-0、1-0、0-1、1-1）进行修正，因为泊松低估了这些比分的概率
修正系数ρ通常为-0.1到-0.15
```

**适用场景**：比分玩法、半全场玩法

### 2.3 4模型集成概率

```
最终概率 = 市场隐含概率×35% + 泊松×25% + Dixon-Coles×25% + 贝叶斯×15%
```

**适用场景**：所有玩法的基础概率

### 2.4 半全场条件概率法

```
Step 1: 半场结果概率矩阵（λ_half = λ_full × 0.45）
Step 2: 动态下半场λ（领先方λ下降，落后方λ上升）
Step 3: 下半场结果概率
Step 4: 映射9种半全场结果
Step 5: 逆转选项×0.6修正（模型高估逆转概率）
```

## 三、资金管理与保本策略

### 3.1 三层资金结构

| 层级 | 占比 | 用途 | 风险 |
|------|------|------|------|
| 稳健层 | 50-60% | 胜平负/让球稳胆2串1 | 低 |
| 容错层 | 25-35% | M串N容错（3串4/4串11） | 中 |
| 搏冷层 | 10-15% | 比分/半全场高赔博冷 | 高 |

### 3.2 4种保本组合方案

**方案1：全包保本**
- 3场比赛，每场双选，组成3串1
- 命中任意1场就不亏，命中2场以上盈利

**方案2：2串1+3串4**
- 2场稳胆做2串1（保本底仓）
- 3场比赛做3串4（容错搏高）
- 2串1命中就保本，3串4命中2场以上盈利

**方案3：共享稳胆+反向**
- 1场超级稳胆共享到所有投注单
- 其他比赛选不同方向，分散风险
- 稳胆命中+任意1场命中就盈利

**方案4：M串N复式**
- 4场比赛，每场1-2个选项
- 组成4串11（6注2串+4注3串+1注4串）
- 命中2场就有回报，命中3场以上盈利

### 3.3 止损与止盈规则

```
单日亏损 > 总资金10% → 停止当日投注
连续亏损3天 → 降低仓位50%，复盘分析
单日盈利 > 总资金20% → 提取50%利润
连续盈利5天 → 回归标准仓位，防过度自信
```

## 四、6大高级分析维度

### 4.1 盘口语言识别（8种模式）
1. 初盘低水→终盘高水：诱盘
2. 初盘高水→终盘低水：真实看好
3. 盘口升盘+高水：阻上
4. 盘口降盘+低水：诱下
5. 水位震荡：不确定
6. 初盘异常：内幕信息
7. 临场剧变：资金大幅流入
8. 欧亚背离：欧指与亚盘矛盾

### 4.2 理论vs实际盘口偏离
```
理论让球 = 主队λ - 客队λ
实际让球 = 亚盘盘口
偏离 > 0.5球 → 有价值机会
```

### 4.3 多视角分析（5模块）
1. 数据视角：历史统计/近期状态
2. 模型视角：泊松/DC/ML预测
3. 盘口视角：欧亚盘口/水位变化
4. 基本面视角：伤停/战意/赛程
5. 逆向视角：热门陷阱/冷门价值

### 4.4 反向指标分析
- 热门陷阱：支持率>70%但赔率<1.5
- 冷门价值：支持率<20%但赔率>5
- 赔率异动：初盘→终盘变动>20%
- 支持率背离：支持率与隐含概率偏差>15%

### 4.5 CLV（赔率变动价值）追踪
```
CLV = (终盘赔率 - 初盘赔率) / 初盘赔率
CLV > 10% → 赔率上升，市场不看好，可能有冷门价值
CLV < -10% → 赔率下降，市场看好，可能是诱盘
```

### 4.6 联赛专攻分析
- 联赛特征：场均进球/主胜率/大球率/平局率
- 球队风格：开局型/慢热型/逆转型/领先后保守型
- 裁判因素：出牌率/点球率/主场偏袒度
- 赛季阶段：争冠/保级/无欲无求

## 五、7大被忽略维度

1. **赛程疲劳**：72小时内比赛→体能下降10-15%
2. **天气影响**：大雨→进球减少，大风→定位球增多
3. **裁判因素**：出牌多的裁判→比赛中断多，进球少
4. **主场优势**：不同联赛主场优势不同（英超10%，西甲15%）
5. **球队风格克制**：控球型克制防守反击，高位逼抢克制慢节奏
6. **更衣室氛围**：内讧/换帅/转会传闻影响表现
7. **旅行距离**：客场旅行>1000公里→表现下降5-10%

## 六、7大典型错误自检（输出前必须检查）

1. ❌ 只看赔率不看概率 → 必须计算EV
2. ❌ 串关过长（>6场）→ 命中率指数下降
3. ❌ 追热门不看诱盘 → 必须检查支持率背离
4. ❌ 忽略伤停影响 → 必须量化伤停影响
5. ❌ 比分/半全场仓位过重 → Kelly系数必须低（0.03-0.05）
6. ❌ 单场比赛多选矛盾选项 → 胜平负主胜和比分客胜不能同时串
7. ❌ 不做保本结构 → 必须有稳健层底仓

## 七、官方规则速查

### 过关上限
| 玩法 | 最大串关 |
|------|---------|
| 胜平负 | 8关 |
| 让球胜平负 | 8关 |
| 总进球 | 6关 |
| 比分 | 4关 |
| 半全场 | 4关 |

### 其他规则
- 单票金额≤6000元
- 倍数范围：2-99倍
- 每注固定2元
- M串N公式：N=2^M-1
- 混合过关上限由最低玩法决定

### 奖金计算
```
单注奖金 = 2 × 赔率乘积 × 倍数
单注奖金≤500万（超过按500万计）
```

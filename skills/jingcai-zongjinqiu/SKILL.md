# 总进球玩法专属技能

## 玩法特点

- **量化最成熟**：8个选项（0/1/2/3/4/5/6/7+球），泊松模型最适合
- **新手友好**：判断比赛进球多少，比判断胜负简单
- **直接对应大小球**：第三方大小球盘口可直接验证
- **过关上限**：6关（比胜平负/让球低）

## 核心分析逻辑

### 1. 泊松模型预测（核心）
- 计算双方预期进球 λ_home + λ_away = 总预期进球
- 泊松分布推导各档位概率
- 全局校准：0球×0.65，1球×0.85（泊松低估低比分概率）

### 2. 大小球盘口验证
- 第三方大小球盘口（通常2.5球）
- 模型大球概率 vs 盘口隐含概率
- 偏差>15%即为价值信号

### 3. 档位集中度分析
- 概率最高的2个档位占比
- 集中度>55%：比赛进球数可预测性高，有价值
- 集中度<45%：比赛进球数不确定性高，谨慎

### 4. 攻防节奏分析
- 双方进攻强度 vs 防守强度
- 近期场均进球/失球
- 比赛风格（对攻/防守反击/控球）

## 专属策略

### 策略1：大小球验证+档位集中
- 大小球盘口验证偏差>15%
- 档位集中度>55%
- 模型概率最高的2个档位
- EV>7%

### 策略2：攻防节奏极端
- 双方都是进攻型球队（场均进球>2.5）
- 或双方都是防守型球队（场均失球<1.0）
- 进球档位可预测性高

### 策略3：联赛特征应用
- 用联赛特征库的场均进球/大球率调整
- 高进球联赛（如荷甲、比甲）倾向大球
- 低进球联赛（如意甲、法甲）倾向小球

## 典型案例

### 案例1：大球价值
- 荷甲：阿贾克斯vs埃因霍温
- 总预期进球3.2球
- 模型3球概率28%，4球概率22%
- 档位集中度50%
- 第三方大小球2.5球，大球赔率1.85
- 3球赔率3.20，4球赔率4.50
- 结论：3球+4球有价值，EV+8.5%

### 案例2：小球价值
- 意甲：尤文图斯vs国际米兰
- 总预期进球1.8球
- 模型1球概率32%，2球概率28%
- 档位集中度60%
- 第三方大小球2.5球，小球赔率1.90
- 1球赔率3.50，2球赔率3.20
- 结论：1球+2球有价值，EV+9.2%

## 注意事项

1. **低比分校准**：泊松模型低估0球和1球概率，必须用校准系数修正
2. **7+球概率极低**：7+球选项概率通常<2%，EV很难为正，谨慎选择
3. **串关上限低**：总进球最多串6关，组合设计受约束
4. **天气影响**：大雨/大风可能减少进球数，必须考虑
5. **赛程密度**：赛程密集的球队可能体能不足，进球数可能下降

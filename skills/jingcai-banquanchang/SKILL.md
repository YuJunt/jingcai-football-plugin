# 半全场玩法专属技能

## 玩法特点

- **最高阶玩法**：9种选项（胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负），需要判断比赛走势
- **逆转选项高赔**：胜负/负胜等逆转选项赔率高（通常>10）
- **比赛节奏关键**：需要判断球队开局/慢热/领先保持/逆转能力
- **过关上限**：4关（与比分相同，高赔玩法不能串太多场）

## 9种选项

| 选项 | 半场 | 全场 | 说明 |
|------|------|------|------|
| 胜胜 | 主胜 | 主胜 | 主队半场领先并保持到终场 |
| 胜平 | 主胜 | 平局 | 主队半场领先，终场被扳平 |
| 胜负 | 主胜 | 客胜 | 主队半场领先，终场被逆转（高赔） |
| 平胜 | 平局 | 主胜 | 半场平局，终场主队胜 |
| 平平 | 平局 | 平局 | 全场平局 |
| 平负 | 平局 | 客胜 | 半场平局，终场客队胜 |
| 负胜 | 客胜 | 主胜 | 客队半场领先，终场被逆转（高赔） |
| 负平 | 客胜 | 平局 | 客队半场领先，终场被扳平 |
| 负负 | 客胜 | 客胜 | 客队半场领先并保持到终场 |

## 核心分析逻辑

### 1. 真正条件概率法（核心，不是简化的p_h×0.65）

**Step 1：半场结果概率矩阵**
- 用泊松模型计算半场进球概率（λ_half = λ_full × 0.45）
- 推导半场胜平负概率矩阵

**Step 2：动态下半场λ**
- 根据半场结果动态调整下半场λ
- 半场领先方：λ下降（保守踢法），但如果是强队可能继续进攻
- 半场落后方：λ上升（猛攻），但如果是弱队可能放弃
- 半场平局：λ基本不变

**Step 3：下半场结果概率**
- 用动态下半场λ计算下半场进球概率
- 结合半场比分，推导全场结果

**Step 4：映射9种结果**
- 半场结果 × 全场结果 → 9种半全场选项概率
- 逆转选项（胜负/负胜）×0.6修正（逆转概率被模型高估）

### 2. 比赛节奏分析（关键）

**球队风格画像**：
- **开局型**：上半场进球多，领先保持能力强→胜胜/负负有价值
- **慢热型**：上半场进球少，下半场发力→平胜/平负有价值
- **逆转型**：落后时反扑能力强→负胜/胜负有价值（但概率低）
- **领先后保守**：领先后容易被扳平→胜平/负平有价值

**近期比赛节奏数据**：
- 近5场半场结果分布
- 近5场下半场进球分布
- 领先保持率/被逆转率

### 3. 逆转选项专项分析
- 胜负/负胜赔率通常>10
- 模型概率通常<5%
- EV很难为正，需要有明确的逆转信号
- 逆转信号：落后方强队/领先后保守/历史逆转记录
- 逆转选项×0.6修正（模型高估逆转概率）

### 4. 半场赔率验证
- 第三方半场赔率（如有）可验证半场概率
- 但半场赔率数据较少，主要靠模型

## P0新增专属工具（3个，必须使用）

### 工具1：htft_frequency_calibration（半全场历史频率校准器）
**用途**：用36联赛历史频率基准校准模型概率，解决模型概率偏差问题
**调用方式**：analyzer MCP → htft_frequency_calibration(model_probs, league_code)
**关键输出**：
- 校准后的9种组合概率（模型70% + 历史频率30%）
- 核心区间概率（胜胜/平胜/负负/平平/平负 = 82.7%）
- 平开头概率（平胜/平平/平负 = 52.8%，超过一半比赛上半场平局！）
- 逆转组合概率（负胜/胜负 = 8%，极端小概率）
- Top3推荐组合
**使用时机**：条件概率法计算出9种组合概率后，必须调用此工具校准

### 工具2：second_half_goal_diff（下半场进球差SHGD指标）
**用途**：SHGD是预测半全场"平→胜/平→负"的最佳指标
**调用方式**：analyzer MCP → second_half_goal_diff(team, league, recent_matches=10)
**关键输出**：
- 下半场场均进球/失球
- SHGD值（>0.5=下半场强势，<-0.5=下半场弱势）
- 半场平局后胜率
- 推荐方向（平→胜候选 / 平→负风险）
**使用时机**：分析"平胜/平负"选项时，必须计算两队的SHGD

### 工具3：team_half_time_profile（球队半场习惯画像）
**用途**：分析球队是"善抢开局"还是"后发制人"
**调用方式**：analyzer MCP → team_half_time_profile(team, league, recent_matches=20)
**关键输出**：
- 半场胜率/平局率/负率
- 半场领先保持率（半场胜→全场胜的概率）
- 半场平局后胜率
- 开局类型：善抢开局/慢热型/慢热落后型/均衡型
- 推荐半全场方向
**使用时机**：每场比赛分析前，必须获取两队的半场习惯画像

## 专属策略

### 策略1：领先保持型（最稳）
- 强队主场，开局能力强
- 半场领先概率>50%
- 领先保持率>70%
- 胜胜/负负赔率合理
- EV>12%

### 策略2：平局半场型
- 两队实力接近，防守好
- 半场平局概率>45%
- 全场结果有倾向（平胜/平负）
- 赔率有价值

### 策略3：逆转博冷（高风险高收益）
- 有明确逆转信号
- 逆转赔率>15
- 模型概率>5%（修正后>3%）
- EV>12%
- 极小仓位（Kelly 0.05）

## 关键参数速查表

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +12% | 正EV阈值（高，因为概率不可靠） |
| Kelly系数 | 0.05 | 仓位计算（低，因为高赔波动大） |
| 过关上限 | 4关 | 最多串4场 |
| 选项数 | 9 | 胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负 |
| 半场λ系数 | ×0.45 | 半场进球约为全场45% |
| 逆转选项修正 | ×0.6 | 模型高估逆转概率 |
| 领先保持率阈值 | >70% | 领先保持型策略 |
| 半场平局概率阈值 | >45% | 平局半场型策略 |
| 逆转赔率阈值 | >15 | 逆转博冷策略 |

## 典型案例

### 案例1：领先保持型
- 英超：利物浦vs伯恩茅斯
- 利物浦主场，开局能力强
- 半场主胜概率58%
- 利物浦领先保持率75%
- 胜胜赔率2.10
- 模型胜胜概率52%
- EV=52%×2.10-1=+9.2%（接近门槛）
- 结合比赛节奏，利物浦近5场4场半场领先并保持
- 结论：胜胜有价值，EV+9.2%（略低于门槛，但节奏数据支撑）

### 案例2：平局半场型
- 意甲：尤文图斯vsAC米兰
- 两队防守都好，实力接近
- 半场平局概率48%
- 全场主胜概率42%（平胜）
- 平胜赔率4.50
- 模型平胜概率28%
- EV=28%×4.50-1=+26%
- 结论：平胜有价值，EV+26%

### 案例3：逆转博冷（不推荐）
- 西甲：皇马vs巴萨
- 巴萨半场领先概率40%
- 皇马逆转概率8%（修正后4.8%）
- 负胜赔率18.00
- EV=4.8%×18.00-1=-13.6%
- 结论：负胜EV为负，不推荐

## 注意事项

1. **真正条件概率法**：不能用简化的p_h×0.65，必须用半场矩阵→动态下半场λ→映射9结果
2. **逆转选项修正**：逆转选项（胜负/负胜）必须×0.6修正，模型高估逆转概率
3. **比赛节奏是关键**：半全场玩法核心是判断比赛走势，不是简单的概率相乘
4. **过关上限低**：最多串4场，组合设计受约束
5. **高赔波动大**：半全场赔率高，短期波动极大，需要500+次投注才能统计验证
6. **半场数据少**：第三方半场赔率数据较少，主要靠模型推导
7. **禁止简化处理**：不能因为"复杂"就跳过半全场玩法，必须用真正条件概率法

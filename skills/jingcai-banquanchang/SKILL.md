# 半全场玩法专属技能

## 1. 用途与触发场景

**用途**：对比赛的半全场结果进行深度分析，识别领先保持型、平局半场型、逆转博冷机会。

**触发场景**：
- 用户要求分析某场比赛的半全场玩法
- 用户要求推荐半场/全场结果
- 用户要求逆转博冷分析
- 用户要求比赛节奏分析

## 2. 分析工作流（5步）

### 步骤1：数据采集
调用以下MCP工具获取数据：
- `data-collector.get_official_odds` - 获取官方半全场赔率（9个选项完整）
- `data-collector.get_support_rate` - 获取支持率
- `data-collector.get_third_party_odds` - 获取第三方半场赔率（可选）

### 步骤2：概率模型
调用以下MCP工具计算概率：
- `analyzer.poisson_predict` - 泊松分布预测（计算半场和全场进球概率）
- `analyzer.dixon_coles` - Dixon-Coles低比分修正
- `analyzer.ensemble_predict` - 4模型集成（全场方向概率）
- 半全场条件概率法：半场矩阵（λ_half=λ_full×0.45）→动态下半场λ→映射9结果

### 步骤3：价值分析
调用以下MCP工具评估价值：
- `analyzer.calculate_ev` - 计算9个选项的EV
- `analyzer.calculate_kelly` - 计算Kelly仓位（0.05）
- `analyzer.reverse_indicator` - 反向指标分析
- 逆转选项（胜负/负胜）×0.6修正（模型高估逆转概率）

### 步骤4：玩法适配度评估
调用以下MCP工具评估玩法适配度：
- `analyzer.play_specific_analysis` - 玩法定制化分析（半全场专属）
- `analyzer.multi_perspective_analysis` - 多视角分析
- 比赛节奏评估：开局型/慢热型/逆转型/领先后保守型

### 步骤5：输出结论
输出以下内容：
- 推荐半全场选项（9选1）
- 半场/全场方向、模型概率、赔率、EV、Kelly仓位
- 比赛节奏判断
- 逆转选项修正说明
- 信心度（高/中/低）
- 推荐理由（结合半场概率、动态下半场λ、比赛节奏）
- 风险提示

## 3. 快速调用脚本

除了手动调用MCP工具，还可以使用自动化脚本一键完成完整分析：

```bash
python3 scripts/analyze_banquanchang.py --match-id <比赛ID> --home <主队> --away <客队>
```

脚本会自动执行上述5步工作流，返回完整的半全场分析结果。

## 4. 关键参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +12% | 正EV阈值（高，因为概率不可靠） |
| Kelly系数 | 0.05 | 仓位计算（低，因为高赔波动大） |
| 过关上限 | 4关 | 最多串4场 |
| 选项数 | 9 | 胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负 |
| 半场λ系数 | ×0.45 | 半场进球约为全场45% |
| 逆转选项修正 | ×0.6 | 模型高估逆转概率 |
| 领先保持率阈值 | >70% | 领先保持型策略 |
| 半场平局概率阈值 | >45% | 平局半场型策略 |
| 逆转赔率阈值 | >15 | 逆转博冷策略 |

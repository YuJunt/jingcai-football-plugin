# 半全场玩法分析方法论（详细版）

> 本文档是半全场玩法的详细方法论，供深入理解时参考。
> 快速使用请查看 SKILL.md 中的工作流指南。

## 一、玩法特点

- **最高阶玩法**：9种选项（胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负），需要判断比赛走势
- **逆转选项高赔**：胜负/负胜等逆转选项赔率高（通常>10）
- **比赛节奏关键**：需要判断球队开局/慢热/领先保持/逆转能力
- **过关上限**：4关（与比分相同，高赔玩法不能串太多场）

## 二、9种选项

| 选项 | 半场 | 全场 | 说明 |
|------|------|------|------|
| 胜胜 | 主胜 | 主胜 | 主队半场领先并保持到终场 |
| 胜平 | 主胜 | 平局 | 主队半场领先，终场被扳平 |
| 胜负 | 主胜 | 客胜 | 主队半场领先，终场被逆转（高赔） |
| 平胜 | 平局 | 主胜 | 半场平局，终场主队胜 |
| 平平 | 平局 | 平局 | 全场平局 |
| 平负 | 平局 | 客胜 | 半场平局，终场客队胜 |
| 负胜 | 客胜 | 主胜 | 客队半场领先，终场被逆转（高赔） |
| 负平 | 客胜 | 平局 | 客队半场领先，终场被扳平 |
| 负负 | 客胜 | 客胜 | 客队半场领先并保持到终场 |

## 三、核心分析逻辑

### 3.1 真正条件概率法（核心，不是简化的p_h×0.65）

**Step 1：半场结果概率矩阵**
- 用泊松模型计算半场进球概率（λ_half = λ_full × 0.45）
- 推导半场胜平负概率矩阵

**Step 2：动态下半场λ**
- 根据半场结果动态调整下半场λ
- 半场领先方：λ下降（保守踢法），但如果是强队可能继续进攻
- 半场落后方：λ上升（猛攻），但如果是弱队可能放弃
- 半场平局：λ基本不变

**Step 3：下半场结果概率**
- 用动态下半场λ计算下半场进球概率
- 结合半场比分，推导全场结果

**Step 4：映射9种结果**
- 半场结果 × 全场结果 → 9种半全场选项概率
- 逆转选项（胜负/负胜）×0.6修正（逆转概率被模型高估）

### 3.2 比赛节奏分析（关键）

**球队风格画像**：
- **开局型**：上半场进球多，领先保持能力强→胜胜/负负有价值
- **慢热型**：上半场进球少，下半场发力→平胜/平负有价值
- **逆转型**：落后时反扑能力强→负胜/胜负有价值（但概率低）
- **领先后保守**：领先后容易被扳平→胜平/负平有价值

**近期比赛节奏数据**：
- 近5场半场结果分布
- 近5场下半场进球分布
- 领先保持率/被逆转率

### 3.3 逆转选项专项分析

- 胜负/负胜赔率通常>10
- 模型概率通常<5%
- EV很难为正，需要有明确的逆转信号
- 逆转信号：落后方强队/领先后保守/历史逆转记录
- 逆转选项×0.6修正（模型高估逆转概率）

### 3.4 半场赔率验证

- 第三方半场赔率（如有）可验证半场概率
- 但半场赔率数据较少，主要靠模型

## 四、专属策略

### 4.1 策略1：领先保持型（最稳）

- 强队主场，开局能力强
- 半场领先概率>50%
- 领先保持率>70%
- 胜胜/负负赔率合理
- EV>12%

### 4.2 策略2：平局半场型

- 两队实力接近，防守好
- 半场平局概率>45%
- 全场结果有倾向（平胜/平负）
- 赔率有价值

### 4.3 策略3：逆转博冷（高风险高收益）

- 有明确逆转信号
- 逆转赔率>15
- 模型概率>5%（修正后>3%）
- EV>12%
- 极小仓位（Kelly 0.05）

## 五、典型案例

### 5.1 案例1：领先保持型

- 英超：利物浦vs伯恩茅斯
- 利物浦主场，开局能力强
- 半场主胜概率58%
- 利物浦领先保持率75%
- 胜胜赔率2.10
- 模型胜胜概率52%
- EV=52%×2.10-1=+9.2%（接近门槛）
- 结合比赛节奏，利物浦近5场4场半场领先并保持
- 结论：胜胜有价值，EV+9.2%（略低于门槛，但节奏数据支撑）

### 5.2 案例2：平局半场型

- 意甲：尤文图斯vsAC米兰
- 两队防守都好，实力接近
- 半场平局概率48%
- 全场主胜概率42%（平胜）
- 平胜赔率4.50
- 模型平胜概率28%
- EV=28%×4.50-1=+26%
- 结论：平胜有价值，EV+26%

### 5.3 案例3：逆转博冷（不推荐）

- 西甲：皇马vs巴萨
- 巴萨半场领先概率40%
- 皇马逆转概率8%（修正后4.8%）
- 负胜赔率18.00
- EV=4.8%×18.00-1=-13.6%
- 结论：负胜EV为负，不推荐

## 六、注意事项

1. **真正条件概率法**：不能用简化的p_h×0.65，必须用半场矩阵→动态下半场λ→映射9结果
2. **逆转选项修正**：逆转选项（胜负/负胜）必须×0.6修正，模型高估逆转概率
3. **比赛节奏是关键**：半全场玩法核心是判断比赛走势，不是简单的概率相乘
4. **过关上限低**：最多串4场，组合设计受约束
5. **高赔波动大**：半全场赔率高，短期波动极大，需要500+次投注才能统计验证
6. **半场数据少**：第三方半场赔率数据较少，主要靠模型推导
7. **禁止简化处理**：不能因为"复杂"就跳过半全场玩法，必须用真正条件概率法

# 半全场玩法典型案例

# 典型案例

### 案例1：领先保持型
- 英超：利物浦vs伯恩茅斯
- 利物浦主场，开局能力强
- 半场主胜概率58%
- 利物浦领先保持率75%
- 胜胜赔率2.10
- 模型胜胜概率52%
- EV=52%×2.10-1=+9.2%（接近门槛）
- 结合比赛节奏，利物浦近5场4场半场领先并保持
- 结论：胜胜有价值，EV+9.2%（略低于门槛，但节奏数据支撑）

### 案例2：平局半场型
- 意甲：尤文图斯vsAC米兰
- 两队防守都好，实力接近
- 半场平局概率48%
- 全场主胜概率42%（平胜）
- 平胜赔率4.50
- 模型平胜概率28%
- EV=28%×4.50-1=+26%
- 结论：平胜有价值，EV+26%

### 案例3：逆转博冷（不推荐）
- 西甲：皇马vs巴萨
- 巴萨半场领先概率40%
- 皇马逆转概率8%（修正后4.8%）
- 负胜赔率18.00
- EV=4.8%×18.00-1=-13.6%
- 结论：负胜EV为负，不推荐

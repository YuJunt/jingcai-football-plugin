# 让球胜平负玩法专属技能

## 玩法特点

- **竞彩特有**：强弱悬殊时引入让球，让球数赛前确定并维持不变
- **3选项无走水**：让球胜/让球平/让球负，无"走水"（与亚盘不同）
- **让平是独立选项**：让平概率>25%且赔率>3.5时有价值
- **过关上限**：8关

## 与亚盘的核心差异

| 维度 | 竞彩让球 | 亚盘 |
|------|---------|------|
| 让球数 | 固定整数（通常±1） | 可细分（平半/半球/一球等） |
| 选项 | 3选项，无走水 | 2选项，有走水 |
| 让平 | 独立选项，有赔率 | 不存在（走水） |
| 过关上限 | 8关 | 通常无限制 |

## 核心分析逻辑

### 1. 让球数合理性判断（核心）
- 计算公平让球 = 主队预期进球 - 客队预期进球
- 对比实际让球数，判断是否合理
- 实际让球 > 公平让球：让球方可能输盘（让平/让负有价值）
- 实际让球 < 公平让球：让球方可能赢盘（让球胜有价值）

### 2. 让平专项识别
- 让平概率>25%且赔率>3.5
- 两队实力接近，但让球方略强
- 让球方赢1球的概率高（净胜=1→让平）

### 3. 赢球输盘风险识别
- 让球方赢球但净胜球不够（如让1球，只赢1球→让平）
- 亚盘上盘高水→赢球输盘风险大→让平/让负有价值
- 让球方近期赢球但多为小胜

### 4. 亚盘水位辅助
- 亚盘上盘高水（>1.0）：赢球输盘风险大
- 亚盘上盘低水（<0.8）：让球方赢盘概率大
- 亚盘水位变动方向：资金流向信号

## 专属策略

### 策略1：让平专项
- 让平概率>25%且赔率>3.5
- 让球方实力略强，但赢球多为小胜
- 亚盘上盘高水
- 综合评分：EV 50% + 让平专项 30% + 亚盘 20%

### 策略2：赢球输盘博冷
- 让球方热门，但亚盘上盘高水
- 让球方近期小胜多
- 让负赔率>3.0且模型概率>25%
- 小仓位博冷

### 策略3：让球胜稳胆
- 让球数合理或偏浅
- 让球方实力明显强于对手
- 亚盘上盘低水
- 模型让球胜概率>60%

## 关键参数速查表

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +5% | 正EV阈值 |
| Kelly系数 | 0.20 | 仓位计算（比胜平负低） |
| 过关上限 | 8关 | 最多串8场 |
| 选项数 | 3 | 让球胜/让球平/让球负 |
| 让平价值概率 | >25% | 配合赔率>3.5 |
| 让平价值赔率 | >3.5 | 配合概率>25% |
| 综合评分权重 | EV50%+让平30%+亚盘20% | 让球玩法专属 |

## 典型案例

### 案例1：让平价值
- 英超：曼城vs阿森纳
- 曼城让1球，让平赔率3.60
- 模型让平概率28%
- 亚盘曼城让1球高水1.05
- 曼城近期赢球多为1球小胜
- 结论：让平有价值，EV+0.8%

### 案例2：赢球输盘风险
- 西甲：皇马vs贝蒂斯
- 皇马让1球，让负赔率3.20
- 模型让负概率27%
- 亚盘皇马让1球高水1.02
- 皇马周中有欧冠，可能轮换
- 结论：让负有价值，赢球输盘风险大

## 注意事项

1. **让球数固定**：竞彩让球数赛前确定，不会像亚盘那样变动
2. **无走水**：让球是3选项，净胜球正好等于让球数时是让平，不是走水
3. **让平常被低估**：让平赔率常被低估，尤其让1球的比赛
4. **亚盘只是辅助**：亚盘与竞彩让球机制不同，只能作为辅助参考，不能直接套用

# 让球胜平负玩法分析方法论（详细版）

> 本文档是让球胜平负玩法的详细方法论，供深入理解时参考。
> 快速使用请查看 SKILL.md 中的工作流指南。

## 一、玩法特点

- **竞彩特有**：强弱悬殊时引入让球，让球数赛前确定并维持不变
- **3选项无走水**：让球胜/让球平/让球负，无"走水"（与亚盘不同）
- **让平是独立选项**：让平概率>25%且赔率>3.5时有价值
- **过关上限**：8关

## 二、与亚盘的核心差异

| 维度 | 竞彩让球 | 亚盘 |
|------|---------|------|
| 让球数 | 固定整数（通常±1） | 可细分（平半/半球/一球等） |
| 选项 | 3选项，无走水 | 2选项，有走水 |
| 让平 | 独立选项，有赔率 | 不存在（走水） |
| 过关上限 | 8关 | 通常无限制 |

## 三、玩法选择决策树

### 3.1 什么时候选让球胜平负？

- **让胜稳胆**：让球盘口≤1球 AND 主队实力强 AND 让胜赔率<1.8 AND 主队赢球概率>60%
- **让平专项**：让平赔率>3.5 AND 让平概率>25% AND 亚盘上盘高水（>1.0）AND 赢球输盘风险大
- **让负价值**：让负赔率<2.5 AND 客队不败概率>50% AND 主队让球过深（>1球）
- **赢球输盘识别**：主队赢球概率高但赢盘概率低 → 让平/让负有价值

### 3.2 什么时候不选让球胜平负？

- 让球盘口=0（平手盘）→ 应该选胜平负（没有让球意义）
- 两队实力接近 → 让球盘口浅，让胜赔率太低
- 进球数预期明确（大球/小球）→ 应该选总进球
- 具体比分有高确定性 → 应该选比分

### 3.3 让球胜平负玩法适配度评分（0-100）

```
score = 0
if 让球盘口0.5-1.5: score += 30
if 亚盘水位异常（上盘高水或下盘高水）: score += 25
if 让平赔率>3.5: score += 20
if 赢球输盘信号明显: score += 15
if 主队主场强势: score += 10
score > 70 → 优先选让球胜平负
score 50-70 → 可选让球胜平负
score < 50 → 考虑其他玩法
```

## 四、核心分析逻辑

### 4.1 让球数合理性判断（核心）

- 计算公平让球 = 主队预期进球 - 客队预期进球
- 对比实际让球数，判断是否合理
- 实际让球 > 公平让球：让球方可能输盘（让平/让负有价值）
- 实际让球 < 公平让球：让球方可能赢盘（让球胜有价值）

### 4.2 让平专项识别

- 让平概率>25%且赔率>3.5
- 两队实力接近，但让球方略强
- 让球方赢1球的概率高（净胜=1→让平）

### 4.3 赢球输盘风险识别

- 让球方赢球但净胜球不够（如让1球，只赢1球→让平）
- 亚盘上盘高水→赢球输盘风险大→让平/让负有价值
- 让球方近期赢球但多为小胜

### 4.4 亚盘水位辅助

- 亚盘上盘高水（>1.0）：赢球输盘风险大
- 亚盘上盘低水（<0.8）：让球方赢盘概率大
- 亚盘水位变动方向：资金流向信号

## 五、专属策略

### 5.1 策略1：让平专项

- 让平概率>25%且赔率>3.5
- 让球方实力略强，但赢球多为小胜
- 亚盘上盘高水
- 综合评分：EV 50% + 让平专项 30% + 亚盘 20%

### 5.2 策略2：赢球输盘博冷

- 让球方热门，但亚盘上盘高水
- 让球方近期小胜多
- 让负赔率>3.0且模型概率>25%
- 小仓位博冷

### 5.3 策略3：让球胜稳胆

- 让球数合理或偏浅
- 让球方实力明显强于对手
- 亚盘上盘低水
- 模型让球胜概率>60%

## 六、典型案例

### 6.1 案例1：让平价值

- 英超：曼城vs阿森纳
- 曼城让1球，让平赔率3.60
- 模型让平概率28%
- 亚盘曼城让1球高水1.05
- 曼城近期赢球多为1球小胜
- 结论：让平有价值，EV+0.8%

### 6.2 案例2：赢球输盘风险

- 西甲：皇马vs贝蒂斯
- 皇马让1球，让负赔率3.20
- 模型让负概率27%
- 亚盘皇马让1球高水1.02
- 皇马周中有欧冠，可能轮换
- 结论：让负有价值，赢球输盘风险大

## 七、注意事项

1. **让球数固定**：竞彩让球数赛前确定，不会像亚盘那样变动
2. **无走水**：让球是3选项，净胜球正好等于让球数时是让平，不是走水
3. **让平常被低估**：让平赔率常被低估，尤其让1球的比赛
4. **亚盘只是辅助**：亚盘与竞彩让球机制不同，只能作为辅助参考，不能直接套用

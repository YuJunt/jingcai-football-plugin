# 混合过关专属技能

## 1. 用途与触发场景

**用途**：设计混合过关投注组合，进行木桶原则校验，优化玩法搭配和串关结构。

**触发场景**：
- 用户要求设计混合过关投注单
- 用户要求多玩法串关组合
- 用户要求过关组合优化
- 用户要求木桶原则校验

## 2. 组合设计工作流（5步）

### 步骤1：收集候选选项
从5个玩法技能的分析结果中，收集所有有价值的选项：
- 胜平负：EV>5%的选项
- 让球胜平负：EV>5%的选项
- 总进球：EV>7%的选项
- 比分：EV>15%且双锁定通过的选项
- 半全场：EV>12%的选项

### 步骤2：玩法搭配决策
调用以下逻辑决定玩法搭配：
- 混合过关得分 = 玩法多样性×0.4 + 赔率提升×0.3 + 确定性均衡×0.3
- 单玩法得分 = 玩法集中度×0.5 + 命中率×0.3 + 串关长度×0.2
- 混合得分 > 单玩法得分 → 选混合过关，否则选单玩法串关

### 步骤3：串关结构设计
根据候选选项的玩法构成，决定串关结构：
- 稳胆+总进球（最稳）：2场稳胆+1场总进球=3串1
- 让球+比分（博冷）：1场让球+1场比分=2串1
- 全玩法混合（高收益）：4种玩法各1场=4串1
- M串N容错：4场比赛+4串11容错

### 步骤4：木桶原则校验（必须通过）
调用以下校验逻辑：
1. 最弱环节检查：每个选项EV>0，最低EV信心度>50%
2. 玩法比例检查：高赔玩法（比分/半全场）≤总场数1/3
3. 上限检查：串关长度不超过最低上限玩法限制
4. 赔率合理性：总赔率在3-50倍之间
5. 相关性检查：同一场比赛不同玩法选项不能同时串

### 步骤5：输出组合方案
输出以下内容：
- 投注单列表（多张投注单组成组合方案）
- 每张投注单的场次、玩法、选项、赔率
- 串关方式（2串1/3串1/4串11等）
- 总投入、预期奖金、保本条件
- 木桶原则校验结果
- 风险提示

## 3. 快速调用脚本

除了手动设计，还可以使用自动化脚本一键完成组合设计：

```bash
python3 scripts/design_mixed_portfolio.py --input candidates.json
```

脚本会自动执行上述5步工作流，返回完整的混合过关组合方案。

## 4. 关键参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 高赔玩法占比上限 | ≤1/3 | 比分/半全场最多占1/3 |
| 总赔率合理区间 | 3-50倍 | 过低无价值，过高不稳定 |
| 最低EV信心度 | >50% | 木桶最弱环节要求 |
| 含比分/半全场上限 | 4串1 | 高赔玩法上限最低 |
| 含总进球上限 | 6串1 | 总进球上限中等 |
| 仅胜平负/让球上限 | 8串1 | 基础玩法上限最高 |

# 比分玩法专属技能

## 玩法特点

- **高赔搏冷**：31种选项，赔率高，抽水最重（>35%）
- **概率最不可靠**：具体比分概率估计误差大，需要最高安全边际
- **双锁定硬条件**：必须同时锁定方向和总进球，才能推荐具体比分
- **过关上限**：4关（最低，高赔玩法不能串太多场）

## 31种选项

- **主胜13种**：1:0、2:0、2:1、3:0、3:1、3:2、4:0、4:1、4:2、5:0、5:1、5:2、胜其它
- **平5种**：0:0、1:1、2:2、3:3、平其它
- **客胜13种**：0:1、0:2、1:2、0:3、1:3、2:3、0:4、1:4、2:4、0:5、1:5、2:5、负其它

## 核心分析逻辑

### 1. 方向+总进球双锁定（硬条件，必须满足）

**条件1：方向锁定**
- 胜平负模型概率最高的方向 > 50%
- 第三方欧指验证一致
- 方向确定性高

**条件2：总进球锁定**
- 总进球模型概率最高的2个档位 > 55%（档位集中度）
- 第三方大小球盘口验证一致
- 总进球确定性高

**两个条件同时满足，才能推荐具体比分。否则跳过比分玩法。**

### 2. 比分收敛度五步法

**Step 1：方向锁定**
- 确定主胜/平局/客胜，概率>50%

**Step 2：总进球锁定**
- 确定总进球区间（如2-3球），Top2概率>55%

**Step 3：Dixon-Coles比分矩阵**
- 用Dixon-Coles模型（rho=-0.13）计算比分概率矩阵
- 修正低比分偏差（0:0/1:0概率被低估）

**Step 4：收敛比分筛选**
- 在锁定方向+总进球区间内，筛选概率最高的2-3个比分
- 收敛比分≤3个（如果>3个，说明不确定性高，不适合推荐）

**Step 5：EV验证**
- 每个推荐比分的EV>15%
- 赔率×概率 - 1 > 0.15

### 3. Dixon-Coles修正（核心模型）
- rho=-0.13（低比分正相关性修正）
- 修正0:0/1:0/0:1等低比分概率
- 比纯泊松更准确

### 4. 比分赔率结构分析
- 热门比分赔率被压低（抽水重）
- 冷门比分赔率可能有价值
- "胜其它"/"平其它"/"负其它"选项概率被低估

## 专属策略

### 策略1：双锁定高确定性
- 方向概率>55% + 总进球Top2>60%
- 收敛比分≤2个
- 每个比分EV>15%
- 小仓位投注（Kelly 0.03）

### 策略2：冷门比分博冷
- 方向确定，但具体比分有冷门可能
- 如主胜确定，但2:1赔率被压低，3:1可能有价值
- 必须有基本面支撑（如主队进攻强，客队防守弱）

### 策略3："其它"选项价值
- "胜其它"/"平其它"/"负其它"概率常被低估
- 当预期进球>4球时，"胜其它"可能有价值
- 但概率极低，需谨慎

## 关键参数速查表

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +15% | 正EV阈值（最高，因为抽水最重） |
| Kelly系数 | 0.03 | 仓位计算（最低，因为概率最不可靠） |
| 过关上限 | 4关 | 最多串4场（最低） |
| 选项数 | 31 | 主胜13+平5+客胜13 |
| 方向锁定概率 | >50% | 硬条件1 |
| 总进球Top2概率 | >55% | 硬条件2 |
| 收敛比分数量 | ≤3个 | 超过则不确定性高 |
| Dixon-Coles rho | -0.13 | 低比分修正参数 |
| 抽水率 | >35% | 比分玩法抽水最重 |

## 典型案例

### 案例1：双锁定比分推荐
- 英超：曼城vs伯恩茅斯
- 方向：主胜概率68%（锁定）
- 总进球：3球28%+4球22%=50%（接近锁定）
- Dixon-Coles比分矩阵：2:0概率18%，3:0概率15%，3:1概率12%
- 收敛比分：2:0、3:0（2个）
- 2:0赔率7.50，EV=18%×7.50-1=+35%
- 3:0赔率12.00，EV=15%×12.00-1=+80%
- 结论：2:0和3:0有价值，双锁定满足

### 案例2：不满足双锁定，跳过
- 意甲：尤文图斯vsAC米兰
- 方向：主胜42%，平局32%，客胜26%（未锁定）
- 总进球：2球30%，1球25%，3球22%（集中度55%，但方向未锁定）
- 结论：方向未锁定，跳过比分玩法，不推荐具体比分

## 注意事项

1. **双锁定是硬条件**：方向和总进球必须同时锁定，否则跳过。不能因为"想推荐比分"而降低标准
2. **抽水最重**：比分玩法抽水>35%，需要最高的EV门槛（+15%）
3. **概率最不可靠**：具体比分概率估计误差大，需要最低的Kelly系数（0.03）
4. **过关上限最低**：最多串4场，组合设计受约束
5. **收敛比分≤3个**：如果收敛比分>3个，说明不确定性高，不适合推荐
6. **禁止用泊松推导替代官方赔率**：必须获取官方比分赔率，不能用模型推导
7. **低比分修正**：必须用Dixon-Coles修正，纯泊松低估0:0/1:0概率

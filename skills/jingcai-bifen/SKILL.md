# 比分玩法专属技能

## 1. 用途与触发场景

**用途**：对比赛的具体比分进行深度分析，识别方向+总进球双锁定机会、收敛比分、高赔博冷。

**触发场景**：
- 用户要求分析某场比赛的比分玩法
- 用户要求推荐具体比分
- 用户要求高赔博冷分析
- 用户要求比分串关组合

## 2. 分析工作流（5步）

### 步骤1：数据采集
调用以下MCP工具获取数据：
- `data-collector.get_official_odds` - 获取官方比分赔率（31个选项完整）
- `data-collector.get_support_rate` - 获取支持率
- `data-collector.get_third_party_odds` - 获取第三方欧指/大小球数据（可选）

### 步骤2：概率模型
调用以下MCP工具计算概率：
- `analyzer.poisson_predict` - 泊松分布预测（计算比分概率矩阵基础）
- `analyzer.dixon_coles` - Dixon-Coles低比分修正（核心，rho=-0.13）
- `analyzer.ensemble_predict` - 4模型集成（方向概率）
- `analyzer.proxy_xg` - 预期进球分析（可选）

### 步骤3：双锁定验证（硬条件）
必须同时满足以下两个条件，才能进入比分推荐：
- **方向锁定**：胜平负最高概率方向 > 50%
- **总进球锁定**：总进球Top2档位集中度 > 55%
- 不满足则跳过比分玩法，不推荐具体比分

### 步骤4：收敛比分筛选与价值分析
调用以下MCP工具：
- `analyzer.calculate_ev` - 计算每个比分选项的EV
- `analyzer.calculate_kelly` - 计算Kelly仓位（0.03）
- 在锁定方向+总进球区间内，筛选概率最高的2-3个比分
- 收敛比分≤3个，每个比分EV>15%

### 步骤5：输出结论
输出以下内容：
- 推荐比分（≤3个）
- 方向、总进球区间、模型概率、赔率、EV、Kelly仓位
- 双锁定验证结果
- 信心度（高/中/低）
- 推荐理由（结合方向确定性、总进球集中度、Dixon-Coles修正）
- 风险提示

## 3. 快速调用脚本

除了手动调用MCP工具，还可以使用自动化脚本一键完成完整分析：

```bash
python3 scripts/analyze_bifen.py --match-id <比赛ID> --home <主队> --away <客队>
```

脚本会自动执行上述5步工作流，返回完整的比分分析结果。

## 4. 关键参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +15% | 正EV阈值（最高，抽水最重） |
| Kelly系数 | 0.03 | 仓位计算（最低，概率最不可靠） |
| 过关上限 | 4关 | 最多串4场（最低） |
| 选项数 | 31 | 主胜13+平5+客胜13 |
| 方向锁定概率 | >50% | 硬条件1 |
| 总进球Top2概率 | >55% | 硬条件2 |
| 收敛比分数量 | ≤3个 | 超过则不确定性高 |
| Dixon-Coles rho | -0.13 | 低比分修正参数 |
| 抽水率 | >35% | 比分玩法抽水最重 |

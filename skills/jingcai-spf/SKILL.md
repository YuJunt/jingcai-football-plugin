# 胜平负玩法专属技能

## 玩法特点

- **基础玩法**：对主队全场结果选"胜/平/负"，3个选项
- **稳胆首选**：赔率1.40-1.70的热门方向，命中率>60%，适合做串关稳胆
- **数据最充分**：直接对应欧指（1X2），第三方数据最丰富
- **返奖率最高**：胜平负单关返奖率最高，长期价值优先选
- **过关上限**：8关

## 核心分析逻辑

### 1. 欧指对比（核心）
- 分别去水后对比概率分布，偏差>5%即为价值
- 竞彩赔率 vs 欧指均值，判断竞彩是否有定价偏差

### 2. 亚盘辅助验证
- 亚盘上盘赢盘概率=主胜概率+平局概率×0.5
- 可交叉验证胜平负概率

### 3. 支持率冷热
- 竞彩官方支持率 vs 赔率隐含概率
- 过热/遇冷信号

## 专属策略

### 策略1：稳胆首选
- 赔率1.40-1.70的热门方向
- 模型概率>60%
- 第三方数据验证一致
- 适合做串关稳胆

### 策略2：平局价值
- 平局赔率常被低估（尤其意甲）
- 当模型平局概率>28%而赔率>3.30时，EV可能为正
- 两队实力接近、防守好的比赛平局概率高

### 策略3：冷门博冷
- 客胜赔率>4.0且模型概率>25%时，可小仓位博冷
- 支持率<20%但赔率>5（市场过度悲观）
- 必须有基本面支撑（如主队伤停严重、客队状态好）

## 关键参数速查表

| 参数 | 值 | 说明 |
|------|-----|------|
| EV门槛 | +5% | 正EV阈值 |
| Kelly系数 | 0.25 | 仓位计算 |
| 过关上限 | 8关 | 最多串8场 |
| 选项数 | 3 | 胜/平/负 |
| 稳胆赔率区间 | 1.40-1.70 | 适合做稳胆 |
| 平局价值赔率 | >3.30 | 配合概率>28% |
| 冷门博冷赔率 | >4.0 | 配合概率>25% |

## 典型案例

### 案例1：稳胆
- 英超：利物浦vs伯恩茅斯
- 主胜赔率1.55，模型概率68%
- 欧指均值1.52，亚盘主让1球低水
- 支持率72%，无过热
- 结论：稳胆，可入串关

### 案例2：平局价值
- 意甲：尤文图斯vsAC米兰
- 平局赔率3.40，模型概率31%
- 两队防守都好，近期平局多
- 欧指平局均值3.35，竞彩略高
- 结论：平局有价值，EV+5.4%

## 注意事项

1. **低赔率风险**：赔率<1.30原则上避免进串关（盈亏平衡概率>76.92%）
2. **热门陷阱**：支持率>70%但赔率<1.5，可能是诱盘
3. **串关EV叠加**：串关EV不是简单相加，抽水和概率误差都会叠加，串关门槛应更高
4. **新手建议**：从胜平负入门，选项少、判断维度单一、数据最充分

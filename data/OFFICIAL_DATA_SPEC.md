# 竞彩官方数据采集规范

> 来源：lottery-data项目 DATA-GUIDE.md 反推 + 竞彩SP快照实证
> 更新时间：2026-09-06

## 一、竞彩官方API

### 1.1 基础Endpoint

```
https://webapi.sporttery.cn/gateway/uniform/football/...
```

### 1.2 5玩法poolCode

| 玩法 | poolCode | 选项数 | 字段名 |
|------|----------|--------|--------|
| 胜平负 | had | 3 | hda (home/draw/away) |
| 让球胜平负 | hhad | 3 | ahh (goal_line + home/draw/away) |
| 比分 | crs | 31 | crs (0:0~5:2 + 胜其他/平其他/负其他) |
| 总进球 | ttg | 8 | ttg (0/1/2/3/4/5/6/7+) |
| 半全场 | hafu | 9 | hafu (胜胜/胜平/胜负/平胜/平平/平负/负胜/负平/负负) |

### 1.3 比赛资讯8项

竞彩官方提供的比赛资讯（点击赛程页"析"按钮展开）：
1. 赛事特征（联赛级别/赛制/历史规律）
2. 历史交锋（两队近N次交锋记录）
3. 近期战绩（两队近5-10场比赛结果）
4. 伤停信息（主力球员伤停情况）
5. 积分榜（联赛排名/积分/净胜球）
6. 未来赛程（后续比赛对手/赛事密度）
7. 球员数据（射手榜/助攻榜/关键球员）
8. 赔率变动（初盘→当前SP变化轨迹）

### 1.4 反爬降级链

```
官方API直连 → curl带UA → detail.php备用页 → agent-browser渲染
```

- 官方API可能返回403，需带Referer和UA
- 每日采集时段建议：11:15（开售初盘）、16:00（午间调整）、19:00（赛前终盘）

## 四、竞彩核心参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 返奖率 | 69% | 官方规则：68%当期奖金+1%调节基金（来源：竞彩网help/2961.html） |
| 单票限额 | ≤20000元 | 单张彩票最大投注金额（来源：竞彩网help/60333.html） |
| 倍数 | 2-99 | 必须为2的倍数 |
| 胜平负/让球过关上限 | 8关 | |
| 总进球过关上限 | 6关 | |
| 比分/半全场过关上限 | 4关 | |
| 混合过关上限 | 最低玩法上限 | 木桶原则 |
| 单关奖金 | 浮动奖金 | 赛后按奖池计算，出票赔率≠最终奖金 |
| 过关奖金 | 固定奖金 | 出票时赔率即最终赔率 |
| 2-3场过关单注上限 | 20万元 | |
| 4-5场过关单注上限 | 50万元 | |
| 6场+过关单注上限 | 100万元 | |
| 保底奖金 | 2元 | 单注不足2元补足至2元 |
| 兑奖期限 | 60个自然日 | |
| 无效场次阈值 | 推迟/中断超36小时 | 过关中去除该场后重算奖金 |

## 五、资金流信号（新增能力）

多时段SP变化 = 资金流向信号：
- SP下降 > 2% = 强资金流入（strength=3）
- SP下降 > 0.5% = 资金流入（strength=2）
- SP下降 > 0.2% = 微弱信号（strength=1）
- SP下降 < 0.2% = 无明显信号

工具：`fund_flow_analysis(snapshots)` — analyzer MCP新增

## 六、置信度过滤（新增能力）

5维打分，<60分过滤：
1. prob_score（模型概率，0-90）
2. consensus_score（赔率共识，0-25）
3. edge_score（模型-市场边际，0-20）
4. steam_score（盘口水位变动，0-30）
5. disp_penalty（离散度惩罚，-15~0）

工具：`confidence_filter_score()` / `confidence_batch_filter()` — analyzer MCP新增

### 7.3 官方API
- 基础Endpoint：`https://webapi.sporttery.cn/gateway/uniform/football/...`
- 赛程API：获取在售比赛列表（含mid）
- 赔率API：按mid获取5玩法SP（had/hhad/crs/ttg/hafu）
- 资讯API：按mid获取8项比赛资讯
- 反爬降级链：官方API → curl带UA → detail.php备用页 → agent-browser渲染
- 采集时段建议：11:15（初盘）、16:00（午间）、19:00（临场）

### 7.4 赛后数据获取
- 赛果：开奖公告页或API
- 官方SP终盘：对阵详情页历史快照
- 赔率变动轨迹：多时段采集对比
- 用于：赛后结算、自进化闭环、模型校准
